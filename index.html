Student Planner is a React app

Run it from the VS Code terminal so the API and PostgreSQL database start with the interface.

  1. Copy .env.example to .env.
  2. Start PostgreSQL with docker compose up -d.
  3. Run npm install, npm run db:migrate, and npm run db:seed.
  4. Run npm run dev.

The app will be available at http://localhost:5173.

See README.md for setup details.
